# Portfólio — Lucas Nobre

Site estático em HTML, CSS e JavaScript, com imagens WebP e paleta azul.

## Abrir e publicar
Abra `index.html` no navegador ou use Live Server no VS Code. Não precisa instalar dependências.

URL esperada no GitHub Pages: https://lucasnobres.github.io/html-css/sites%20clientes/portifolio/

O GitHub Pages precisa estar habilitado na branch main e pasta raiz do repositório. Se o endereço de publicação mudar, atualize canonical, Open Graph, JSON-LD e sitemap.xml.

## Arquivos
- index.html: conteúdo e metadados SEO.
- style.css: estilos, responsividade e animações.
- app.js: menu, navegação, relógio e controle de movimento.
- assets/: prévias dos projetos, favicon e imagem de compartilhamento.
- sitemap.xml: URL canônica para submissão ao Search Console.

O robots.txt é consultado somente na raiz do domínio. Nenhuma regra global de rastreamento de outros projetos foi alterada. As fontes DM Sans e Manrope são carregadas do Google Fonts com fallback local.
